Un espace public. Votre laboratoire privé.

Le site GitHub Pages contient l’interface et les accès rapides. Les conversations, la mémoire, les outils et les mesures restent sur JARVIS.

1. Ouvrir le tunnel existant

Dans le Launcher, choisissez votre poste puis « Tunnel JARVIS ». Le compagnon JL-01 déjà installé reste compatible. Aucun nouveau compte ni nouvelle clé ne sont nécessaires.

2. Ouvrir l’espace connecté

http://localhost:8765/launcher2/ utilise le tunnel SSH. Si vous êtes déjà connecté à l’interface JARVIS sur cette même adresse, la session est réutilisée. Sinon, connectez-vous avec votre compte JARVIS. N’entrez aucun mot de passe dans une page publique.

3. Converser ou confier une mission

Prompt IA et Conversation vocale partagent le même fil. Le microphone nécessite l’autorisation du navigateur. Une transcription est proposée pour relecture avant envoi. Le mode Mission agentique enregistre l’objectif dans le planificateur persistant, suivi dans Sandbox. Une commande réussie n’est pas à elle seule une réception complète de mission.

4. Lire les preuves

Sélectionnez une mission. Dépliez une tâche ou une opération pour voir l’agent, les commandes disponibles, la sortie, le code de retour et les références de preuve. Une coche exige une tâche validée et une preuve réussie. Le pourcentage des tâches ne mesure pas le temps restant. Vous pouvez agrandir ou réduire Sandbox et reprendre une mission interrompue.

Compagnon macOS

Réutilisez le compagnon V1 quand il fonctionne déjà. Pour un nouveau poste, téléchargez ses sources et l’installateur, puis consultez la documentation du dépôt V1 avant installation. Les contrôles de profil/matériel et les clés existantes sont conservés.

Open WebUI

Le raccourci localhost:3000 nécessite son propre tunnel existant vers le port WebUI. Le tunnel conversation du port 8765 ne le crée pas. Le Launcher ne collecte pas les identifiants de WebUI, SSH ou Codex.

Dépannage

« Indisponible » signifie qu’aucune mesure fiable n’a été reçue. Vérifiez le tunnel, la session, puis les services. Un refus du microphone, un moteur occupé ou une API inaccessible est affiché comme tel ; aucune réponse locale fictive n’est générée.
