# Mission 22 — intégration du moteur durable

Branche de travail dédiée, réception en cours. Les demandes agentiques transmettent la conversation et le projet. Une opération initiée depuis un chat ordinaire peut retourner mission_id : le Launcher sélectionne alors cette mission et remet son curseur à zéro. Les événements du nouveau moteur proviennent de SQLite ; les anciennes missions restent lisibles.

Le moteur canonique appartient au dépôt JARVIS-Local-AI-Lab, dossier agentic/engine_v2. Le script d'installation du Launcher ne doit plus écraser ce moteur avec la copie historique backend/missions.py. Il installe uniquement les actifs graphiques après vérification du prérequis V2. Les accès rapides, la voix, le tunnel et les défilements internes sont conservés.

Tests statiques JavaScript et tests existants de format et modèle de tâches réussis. Réception connectée et publication de cette branche à vérifier séparément ; aucun GO global anticipé.
