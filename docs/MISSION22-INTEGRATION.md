# Mission 22 — intégration du moteur durable

Branche de travail dédiée, réception en cours. Les demandes agentiques transmettent la conversation et le projet. Une opération initiée depuis un chat ordinaire peut retourner mission_id : le Launcher sélectionne alors cette mission et remet son curseur à zéro. Les événements du nouveau moteur proviennent de SQLite ; les anciennes missions restent lisibles.

Le moteur canonique appartient au dépôt JARVIS-Local-AI-Lab, dossier agentic/engine_v2. Le script d'installation du Launcher ne doit plus écraser ce moteur avec la copie historique backend/missions.py. Il installe uniquement les actifs graphiques après vérification du prérequis V2. Les accès rapides, la voix, le tunnel et les défilements internes sont conservés.

Tests statiques JavaScript et tests existants de format et modèle de tâches réussis. Actifs déployés sur la passerelle canonique.22 assertions Chromium connectées réussissent sur la mission21 réelle : sept tâches, six coches, événements JARVIS et neutres visibles, défilements indépendants sur trois formats. La réception globale du moteur garde ses réserves, notamment l’enrôlement Tailscale du Dell. Les preuves expurgées sont dans la PR8 de JARVIS-Local-AI-Lab, docs/missions/22/RECEPTION-NAVIGATEUR-FINALE.json.


L’attente externe, la reprise automatique, la publication et l’interruption ont des libellés distincts. Le bouton de reprise réutilise les checkpoints ; il ne valide aucune tâche. Les événements Codex restent attribués à Codex. Le rechargement du chat après fin de mission réutilise les messages canoniques. V1 reste inchangée.


Les sept rapports sont accessibles par liens authentifiés dans les tâches ;07 reste sans coche. Le navigateur a vérifié le rapport réellement servi, l’état d’attente externe et l’événement de blocage. Le backend conserve le journal complet, parcouru sur14 pages API ; la vue courante affiche les150 événements les plus récents. Le même cookie et les mêmes checkpoints ont survécu au redémarrage de service. Aucune réception complète21 ni test direct Tailscale revendiqué.
